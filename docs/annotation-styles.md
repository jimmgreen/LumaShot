# 标注属性

## 序号组合

序号支持引导线、箭头、文本标签、虚线框、高亮区域和放大说明；默认引导线。
拖动确定终点/区域，点击使用默认范围。文本标签放置后进入输入，之后可以
点击标签（序号工具）或双击（选择工具）编辑。V 可整体移动；组合存为一个
Mark，移动、撤销重做及导出保留序号与附属内容。放大说明显示冻结截图的
局部真实像素，倍率 2 倍，边缘采样限制在截图内。

定位针轮廓由圆弧和尖点到圆的两条切线构成，内部白圆与数字同心。
新增 96/144/192 DPI 相切几何验证，组合移动/撤销/导出验证。
本轮 build.bat 和 capture/render/controls/reselect/toolbar 通过；实际绘制
预览位于 build/number-previews/number-combinations.png、number-catalog.png。

最新程序为 `build/LumaShot.exe`。
类型：标准、双向、弯曲、手绘、三角、圆点起点。
头部：实心三角、空心三角、圆角三角、菱形、圆形、短箭头、宽箭头、
细长箭头、弧形箭头、斜切箭头、无箭头（线）。两者独立选择，亚克力

三角类型使用渐宽的实心箭杆，线型作用于其他类型的描边箭杆。
短线段自动限制头部尺寸。几何模型同时供绘制与选中边界使用。
