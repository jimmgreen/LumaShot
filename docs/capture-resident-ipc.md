# 聊天截图：复用 LumaShot 常驻进程

快传 0.3.78 与 LumaShot 常驻截图接口 v1 配套。更新两个应用后，聊天截图优先复用正在运行的 LumaShot；不增加后台服务或第二个常驻截图进程。独立软件未启动、或明确不支持协议时，使用随包单次截图组件。版本探测超时、请求未确认、忙碌和截图错误不会再启动第二份截图。

## 流程

快传隐藏窗口（可选）并同步桌面刷新，向 LumaShot.Host 发送版本化 WM_COPYDATA 请求。LumaShot 在已有消息循环上启动截图，工作线程生成 PNG，并在清理截图窗口后通过系统事件通知成功、取消或错误。双方等待系统事件/进程句柄，没有截图轮询，也没有空闲 IPC 线程、定时器或常驻帧缓存。

会话使用随机 128-bit 标识；快传预先创建三个本地事件，LumaShot 打开已有事件，监视调用方进程退出。取消时停止并等待本次导出，清理本次已写入结果，然后通知快传；取消、正常完成均保留常驻进程。忙碌请求不能覆盖现有会话。文件仍通过原子移动生成，不覆盖已有目标。

图片预览经 Tauri asset 协议直接读取 `$APPCACHE/chat-captures/**`，不再将整图读入 Rust、编码 Base64 后跨 IPC 复制。PNG 检查仅读取文件头；原图路径保留用于发送。20MiB 内 PNG/GIF 进入原有输入框，较大媒体与视频保持文件附件逻辑。会话/账号切换保护和手动发送行为保持。

## 验证

- LumaShot `scripts/test-capture-ipc.ps1`：真实进程、合成画面；完成、Esc 取消、重复完成、忙碌拒绝、显式 IPC 取消、无效参数、已有文件保护、10 次热循环，以及调用方退出后取消并继续截图。
- 全程检查宿主 PID 不变、剪贴板序号不变。热循环句柄数量稳定；合成测试不代表真实桌面的耗时基准。
- 快传 Rust 测试验证事件唯一性、手动重置、进程退出等待、PNG 校验；显式集成测试通过真实 LumaShot 取消并确认宿主仍运行。
- 前端测试覆盖 asset 权限边界、预览大小阈值、截图草稿与原会话保护。

安装交付包含两端安装包。旧版 LumaShot 不具备常驻回传接口；只更新快传会继续使用兼容单次组件。构建过程不安装或替换当前运行的软件。
