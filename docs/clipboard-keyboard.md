# 剪贴板键盘操作

## 快捷取用

1. 先在 QQ 等目标程序中点击要插入内容的输入框。
2. 按剪贴板快捷键（默认 Win+V）打开快捷小窗。小窗不激活，输入焦点保持在目标输入框。
3. 用 ← / → 切换全部、收藏、文本、图片、文件；↑ / ↓ 选择历史记录。Home、End、PageUp、PageDown 也可移动选择。
4. Enter 插入并关闭；Shift+Enter 只插入纯文本，去掉 HTML / RTF 格式。图片和文件不支持纯文本插入。
5. F2 开启或关闭连续取用。开启后插入仍保留小窗，可继续上下选择、Enter 插入。
6. Esc 或再次按剪贴板快捷键关闭。输入普通字符会关闭小窗并将字符交给原输入框；点击窗外、切换窗口或改变目标输入控件也会关闭。

鼠标可切换分类、选择并点击记录插入。类别与收藏来自同一份历史。快捷小窗只负责取用，管理收藏、搜索、预览、删除仍在侧边栏展开的完整剪贴板中完成。

临时键盘钩子仅在快捷小窗使用期间接管未加 Ctrl / Alt / Win 的导航键和 Enter、Esc、F2；已经接管的按键会消耗对应松开事件后退出，避免将 Enter 松开泄漏到聊天输入框。程序生成的输入不被接管。输入法候选窗口通过系统 IME 可访问性事件检测，检测到候选窗口时关闭或暂不打开小窗；不同输入法的事件支持仍需要实机验证。

## 完整剪贴板与收藏

点击侧边栏或托盘剪贴板入口打开完整面板。顶部图钉及 F2 控制固定/取消固定，取消固定后等失焦再收起。完整面板需要键盘焦点来搜索、编辑及管理；固定面板的旧键盘粘贴方式仍保留，连续键盘取用推荐使用快捷小窗。

记录上的星标和 Ctrl+D 用于收藏或取消收藏；“收藏”分类集中展示收藏项。收藏优先显示、随历史保存在本机，普通容量淘汰及“清空历史（保留收藏）”不会移除收藏。删除单条或确认“清空全部记录”仍会删除收藏。面板固定与条目收藏是独立功能。

## 粘贴边界

粘贴等待触发按键、鼠标按钮和修饰键松开，只发送 Ctrl+V，不发送 Enter。快捷小窗在加载记录和发送粘贴前检查原窗口、进程及可识别的输入控件，整个过程不调用激活或恢复焦点操作。若目标不允许自动输入，内容仍可手动粘贴；发送成功不代表接收程序已经接受内容。

文本历史同时保存源剪贴板提供的 HTML / RTF；此前已丢失的格式无法恢复。纯文本使用完整 Unicode 数据，不使用截断的列表预览。

自动测试只使用合成窗口和隔离或替代剪贴板，不使用个人聊天或剪贴内容。快捷小窗测试区分纯键盘路由状态验证、窗口显示验证和跨进程粘贴验证：跨进程测试通过内部导航消息驱动小窗，用真实 Ctrl+V 检查目标输入与焦点保持，不等同于物理按键或 QQ 本体兼容性验证。可选命令 `lumashot_clipboard_keyboard_live_test.exe --quick` 需要可交互输入桌面。

本次日志与浅色/深色、高 DPI 预览位于 `build/clipboard-quick/`。

快捷小窗底栏仅显示分类、选择和连续取用提示；Enter、Esc 操作不变。鼠标停在小窗内时滚轮滚动列表，不滚动后方输入程序；滚动遵循系统行数设置，累计高精度滚轮的小幅增量，右侧细条显示当前位置。
