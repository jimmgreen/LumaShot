# 剪贴板快捷键与连续粘贴

设置 → 全局快捷键 → 剪贴板：点击后录入组合键，退格清除，Esc 取消录入。默认 Win + V；保留用户已经保存的自定义设置。

Win + V 是 Windows 自带剪贴板快捷键。仅当 LumaShot 剪贴板启用、配置为 Win + V 且快捷键策略允许时，接管这一组合；关闭功能或更改组合后释放。其他快捷键不拦截。不修改 Windows 的剪贴板设置。

连续插入到 QQ 等输入框：

1. 点击目标输入框，按 Win + V 打开面板。
2. 点击面板顶部图钉，开启连续粘贴。
3. 单击记录插入当前内容，再单击下一条。面板、搜索和滚动位置保持不变；粘贴操作不发送 Enter。
4. 空格预览；再次点击图钉恢复普通选择模式，Esc 收起。

连续模式下，点击记录时跟随当前输入窗口，鼠标松开后插入；记录和粘贴按钮不抢走输入框的焦点。插入前再次检查目标窗口和进程，在等待粘贴期间切到其他窗口、剪贴板改变或目标不允许输入时，取消自动粘贴并给出提示。

当前操作一次插入一条；前一条仍在准备时提示稍候。没有自动发送聊天消息，也不承诺不同权限级别的应用能自动粘贴。

展开面板可拖动四边和四角调整尺寸，最小 400 × 480 DIP；尺寸与位置一并保存。列表页容量、搜索框、滚动条和底栏随窗口调整，折叠条仍为 28 × 96 DIP。
