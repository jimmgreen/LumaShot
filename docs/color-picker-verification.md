# 自定义颜色与画笔图标

2026-09-15：使用独立矢量画笔图标；自定义颜色改为截图内的亚克力浮层，复用冻结截图的模糊背景，不启动持续渲染。

## 使用

- 选择画笔、文字或形状工具，点击属性栏的「自定义颜色」。
- 拖动二维色板和色相条；HEX / RGB 支持键入、上下按钮、方向键及滚轮调整。
- 点击字段默认全选；Tab 切换输入，Enter 确认当前字段。
- 点击关闭或面板外接受颜色，Esc / 右键恢复打开前颜色。
- 最近颜色在当前程序会话中保留，最多 7 项；加号加入当前颜色。
