# 手绘箭头整体曲线拟合

手绘箭头按主要走向重新拟合，不逐点插值。先按轨迹距离重采样并简化细小修正，再用最小二乘法将整条轨迹拟合为少量三次贝塞尔曲线。拟合中迭代修正点位参数，避免浅弧被压低。只有整体误差较大时才分段，相邻段共享切线方向，避免拼接处折角。

起终点保持固定，中间允许适当偏离原轨迹，从而消除局部鼓包、小折返和多余拐点，保留主要弯曲与较大的回环。端点方向从简化前的轨迹估计，避免简化后的长弦造成整体曲线收缩。

末端方向使用平滑轨迹的切线，不直接采用最后两次鼠标事件的方向。实心箭头的线尾接到箭头内部轴线上；空心箭头在后缘外预留线帽空间，再平滑衔接，避免线条穿入空心区域。箭头尖端保持在拖动终点。

起终点接近或重合的手绘轨迹也可提交。移动端点时同步更新轨迹端点，避免重新连接到旧端点产生折返。原始采样点不会被平滑结果替换，继续支持编辑和撤销重做。

处理仅发生在绘制、编辑或导出时，不增加空闲刷新循环。重采样段数最多 1024，拟合最多递归六层，限制长时间手绘的处理与输出几何规模。

## 验证

`build.bat` 构建通过。手绘专项 20 项检查通过，覆盖非均匀采样抖动、保留大弯、固定端点、末端回抖、实心和空心连接、像素连续性、闭环、重复点、端点编辑及撤销重做。大 U 弯测试的多余曲率换向从 6 次降为 0 次，浅弧最大偏差约 3.5 像素。两万个采样点的生成实测约 1.7 ms，输出几何数量有上限。包含绘制、选择编辑、贴图和鼠标截图的 9 项相关回归测试全部通过。

运行 `build\lumashot_hand_arrow_test.exe --preview`（项目根目录）可用实际图片导出渲染器重建 [整体拟合对比](hand-arrow-fit-preview.png) 与 [箭头衔接对比](hand-arrow-preview.png)。整体拟合对比左侧为原轨迹，右侧为重新拟合后的箭头，包含大 U 弯的鼓包、S 弯的小修正、急转及小折返。
