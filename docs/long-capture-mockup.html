流程从框选到导出

① 框选沿用现有选区，也可单击窗口或控件自动框选。工具栏新增「长截图」按钮，快捷键 L。
② 锁定并解冻选区锁定，冻结遮罩淡出，露出实时桌面；覆盖层只在控制条和预览面板上接收鼠标，其余区域鼠标穿透。
③ 滚动采集自动模式向选区中心所在窗口发送滚轮；在选区里滚动滚轮会切换到手动模式。每次画面稳定后采集一帧，放到后台拼接。
④ 自动结束连续 2 次滚动后画面无变化，判定到达底部；也可按 Enter 提前完成。超过高度上限时提示。
⑤ 预览与导出用导航图裁剪首尾，可以标注、识别文字、贴到桌面、复制或保存 PNG。PNG 在后台分块编码。

算法拼接流水线（后台线程）

采集帧（物理像素，BGRA） ├─ 稳定判定：与上一次采样的行签名一致，才认为滚动惯性结束（不用固定 Sleep） ├─ 行签名：每行 64 位哈希 + 灰度均值；右侧 ≤ 24 px 若只有滚动条滑块在动，匹配时剔除 ├─ 固定区域：与上一帧比较，顶部 / 底部连续相同的行视为吸顶栏或底栏， │ 只在首段 / 末段保留 ├─ 位移估计：用哈希匹配为候选位移投票，再在 ¼ 下采样灰度图上做 NCC 验证（≥ 0.92） │ → 精确到 1 px；页面里重复出现的内容取最接近预测位移的候选 ├─ 追加条带：只存新增的行，不重复保存重叠部分；条带列表加每段偏移 └─ 失败：没有重叠 / 相似度不足 → 暂停，交给用户（撤回、仍然拼接、完成）

拼接模块是纯函数，放在 src/capture/stitcher.*，可以用合成图片单测：吸顶栏、滚动条、重复纹理、动画区域、跳段、1 px 位移、负坐标屏幕。

架构接入现有模块

  • src/ui/toolbar.cpp：新增动作 id 17「长截图」，放在 OCR 与录制之间，窄屏布局沿用加权槽位。
  • src/capture/scroll_session.*：状态机（锁定 → 采集 ⇄ 暂停 → 失败待确认 → 完成 / 取消），带取消代次；取消后丢弃未完成的结果。
  • src/capture/scroll_driver.*：对目标 HWND 发送 WM_MOUSEWHEEL（找不到时改用 SendInput，只在选区中心发送），按步长和速度门控，不做忙等。
  • src/ui/scroll_panel.*：控制条和实时预览。文字统一用 TextRenderer / LumaText 绘制，Acrylic 与深浅主题复用 controls.*。
  • src/ui/long_image_view.*：结果窗口，按 D2D 最大位图尺寸分块，只绘制可见的块；标注模型沿用 model/。
  • 导出：WIC 逐条 WritePixels 写 PNG，编码不占 UI 线程；剪贴板沿用「粘贴为文件」。

边界异常与限制

  • 采集期间无常驻循环：只在滚动事件或步进定时器触发时采集，暂停时计时器停止。
  • 高度上限默认 30,000 px（920 宽时约 105 MB BGRA）。达到上限自动停止并提示，可以在设置里修改。
  • 懒加载页面：画面没变化时先等 300 ms 再判断，避免把「加载中」当成到底。
  • 动画 / 视频区域：投票时剔除逐帧变化的行；相似度仍不足时进入异常状态（见第 4 页）。
  • 无法滚动的窗口（游戏、自绘控件）：3 次滚动都没位移时，提示改用手动滚动或拖动滚动条。
  • 选区跨屏或 DPI 不一致：首版限制在单个显示器内，跨屏时裁剪并提示，做法与录制一致。
  • 首版不支持横向滚动，也不支持选区包含多个独立滚动区域的情况。
