# 长截图（滚动拼接）

设计稿：`docs/long-capture-mockup.html`（已确认）。本文件记录 v1 的实现与约束。

## 入口

- 截图选区工具栏右侧“长截图”按钮（录制按钮左侧），或选区后按 `L`。
- 选区至少 32×32 物理像素，并被裁剪到选区中心所在的显示器。
- 贴图编辑、聊天回传模式下不可用；同一时间只运行一个长截图会话，会话进行中截图热键被忽略。
- 进入后冻结遮罩关闭，桌面恢复可滚动；v1 不携带选区内已画的标注（长图标注属于第二阶段）。

## 拼接会话（`src/longshot/session.*`）

- 窗口：选区描边框（透明、鼠标穿透）、底部控制条、右侧实时缩略面板；三者都设置
  `WDA_EXCLUDEFROMCAPTURE`，不会被拼进结果。
- 控制条和面板是 UpdateLayeredWindow 分层窗口：窗口区域（SetWindowRgn）对它们无效，所以外形交给 DWM 原生圆角、
  描边和阴影，由 DWM 裁剪 acrylic；绘制时铺满整个矩形，不再画第二层圆角（否则四角会露出 acrylic）。
- 控制条和面板互不重叠：优先缩短面板，其次把控制条横向移开，最后移到选区上方。
- 设计检查：`lumashot_long_capture_test --preview build\long-capture-preview [--dark]` 会在本进程内临时解除
  捕获排除，保存控制条和面板的截图（仅用于审阅，这种模式下不校验拼接像素）。
- 工作线程循环：抓取选区（`CaptureRegion`，BitBlt+CAPTUREBLT）→ `Stitcher::Add` → 发布快照到 UI。
  UI 线程只做绘制；没有常驻渲染循环，快照到达时才重绘。
- 自动模式（默认）：对选区中心发送滚轮，按实测“像素/格”调整格数，使每步位移约为可视内容高度的
  35% / 55% / 75%（慢 / 中 / 快）。
- 手动模式：用户自行滚动；在选区内转动真实滚轮会自动切换为手动（低级鼠标钩子，忽略注入事件）。
- 等待画面稳定：先等 90 ms，然后每 55 ms 采样，最长 1200 ms。
- 结束条件：连续两次画面不变（到底）、达到最大高度（默认 30 000 px）、用户按“完成”/Enter。
- 快捷键：Space 暂停/继续，A 自动，S 调速，Backspace 撤销上一段，Enter 完成，Esc 取消
  （已有 ≥3 段时需确认）。
- 异常：无重叠（滚动过快）会回滚一次并减半步长；匹配度低时提示“仍然拼接 / 重试”；窗口不响应滚轮时
  改为手动并提示。

## 拼接算法（`src/capture/stitcher.*`）

- 每行计算指纹（降采样亮度哈希），排除右侧滚动条列和上下固定区域（吸顶栏、底部栏）。
- 候选位移：行哈希投票 → 全范围扫描 → 亮度模糊匹配；匹配度阈值 0.82，最少重叠 24 行。
- 同位置相似度 ≥ 0.97 视为未滚动。滚动条由右侧“持续变化列”识别，导出时可裁掉。
- 合成：首帧顶部固定区 + 各段新增行 + 末帧底部固定区；`Compose(true)` 去掉滚动条。
- 单元测试：`tests/stitcher_test.cpp`（ctest `long_capture_stitch`），全部使用程序生成的合成页面。

## 预览窗口（`src/longshot/viewer.*`）

- 独立窗口（任务栏可见），左侧大图、右侧导航缩略图与操作栏。
- 大图按 512 行分块上传为 D2D 位图，只保留可见块及上下各一块；缩放低于 50% 时按 2^n 盒式滤波降采样（最多 1/8），
  位图内存与屏幕面积成正比，而不是与图片面积成正比。
- 缩略图与留白边检测在工作线程生成。
- 操作：适应宽度 / 100%、Ctrl+滚轮缩放、拖动平移、拖动缩略图视口、上下拖动裁剪手柄、
  显示拼接缝、去除滚动条、裁掉两侧留白、重新截图、识别文字、钉到屏幕、复制、保存。
- 复制/保存/贴图的像素裁剪与 PNG 编码都在后台线程完成；窗口关闭时结果被丢弃。
- 无标注时复制/保存直接从原图的裁剪视图（`PixelView`）编码，不再先拷贝一份；贴图只拷贝一次，识别文字与显示共用同一份像素。
- 复制遵循“粘贴为文件”偏好；保存目录与普通截图共用并记忆。
- 贴图：超过工作区高度的图片初始缩放到工作区 90% 高度。

## 长图标注（v2，`src/longshot/annotations.*`）

- 入口：预览窗口操作栏「标注」或按 `E`。把**当前可见的那一段**长图交给普通截图编辑器，
  编辑器精确覆盖在预览窗口的图片区域上（与贴图标注共用同一条编辑路径，保留全部标注工具）。
  缩放低于 35% 时先放大到 100%，保证能精确落笔。
- 非破坏式：原始像素永不修改；标注以长图像素坐标保存在预览窗口的 `Document` 中。
  - 进入编辑时只取出与可见段相交的标注（换算到段坐标），完成后替换回去，其余标注不动。
  - 可反复进入、再次编辑已有标注；Esc 取消不改变任何标注。
  - 每次完成算一步：`Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`）撤销重做，右侧「标注」区也有撤销 / 重做 / 清除。
- 合成时机：只在显示和导出时合成。
  - 显示：受影响的 2048 行图块用软件渲染（`Renderer::Flatten`）重新合成，所见即所得。
  - 导出（复制 / 保存 / 贴图 / 识别文字）在后台线程按 4096 行分带合成，避免 D2D 目标尺寸上限；
    马赛克始终从整张长图取样，分带接缝不可见（`long_capture_annotation` 测试逐像素验证）。
  - 贴图显示带标注的图，文字识别用干净像素。
- 编辑器里的 保存 / 复制 / 贴图 / 识别文字 按钮会先结束编辑，再对**整张长图**执行该操作（而不是只导出可见段）。
- 编辑期间预览窗口被禁用；预览窗口关闭后迟到的编辑结果被丢弃。
- 有未导出的标注时关闭或重新截取会先确认（默认按钮是“继续编辑”）。
- 缩略图右侧的品红短条标出标注所在位置。

## 内存与性能

- 拼接内容按 512 行分块存放（`make_unique_for_overwrite`，不清零、不整体扩容），撤回时整块释放。
- 撤回历史（32 步）保存增量：上一帧的每一行引用已拼接内容中的对应行（滚动对齐行，或顶部固定栏对应的首帧行），
  只存两者不同的列区间。底部固定栏整行保存，滚动条滑块只存几列。撤回后像素逐位还原（`CheckDeltaUndo`）。
- `std::move(stitcher).Compose()` 边拷贝边释放内容块；会话先取元数据再合成。
- 会话缩略图撤回时截断而不是整张重算；首帧被迟到重绘刷新时（`ContentEpoch()`）才重建。
- 基准：`lumashot_long_memory_bench`（ctest `long_capture_memory`），合成页面，1180×900 选区拼到 30 000 px（最终图 135 MB）。
  统计各阶段进程私有提交内存的峰值增量（1 ms 采样）。

| 阶段 | 优化前 | 优化后 |
|---|---|---|
| 拼接到上限：峰值 / 常驻 | +398 MB / +290 MB | +150 MB / +146 MB |
| 每帧拼接耗时 | 11.8–13.2 ms | 7.1–7.9 ms |
| 合成后净增 | +135 MB | −10 MB（拼接器被消耗） |
| 预览翻页：常驻 / 每步绘制 | +66 MB / 20 ms（最大 73 ms） | +20 MB / 8.6 ms（最大 16 ms） |
| 缩小到 6.5% 翻页 | 全分辨率块（最多约 145 MB） | +0 MB / 14 ms |
| 贴图导出峰值 | +263 MB（1.95×图片） | +132 MB（0.98×） |
| 贴图常驻（无标注） | 两份图片 | 一份（识别文字共用） |

预览窗口首次绘制约 +84 MB，大部分是 GPU 设备；软件渲染可省约 36 MB，但翻页绘制慢一倍，因此保留 GPU（关闭窗口即释放）。

## 已知限制（v1）

- 仅纵向滚动；不支持横向拼接。
- 页面内动画、视频、随滚动变化的内容可能导致匹配度低，需要重试或手动滚动。
- 贴图合成面最大边长 16 384 px：很长的图片贴到桌面后最大缩放比例受限（30 000 px 高约 50%）；复制和保存不受此限制。
- 单次标注的范围是当前可见段；跨越很长距离的标注需要缩小后再画（缩放 ≥ 35%）。
