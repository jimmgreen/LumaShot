# LumaShot 剪贴板功能差距与优先级建议

日期：2026-09-21。范围：当前工作区源码与文档静态审阅，结合 GitHub 上 CopyQ、Ditto、ShareX 的公开资料。未读取个人剪贴板、偏好或文件内容，未执行运行时验证；以下兼容性风险不是已复现故障。本次仅新增分析文档，不修改应用、不构建或安装。

## 结论

现有功能已具备日常使用基础。下一步应优先提高历史恢复的兼容性和隐私控制，再连通截图/OCR能力，而不是继续增加预览装饰或照搬完整剪贴板管理器。

## 已有能力及证据

- 文本、图片、文件路径历史；去重、分类、收藏、排序及容量淘汰：src/clipboard/history.h。
- Unicode 文本同时保留 HTML/RTF；Shift+Enter 纯文本粘贴：src/clipboard/native.cpp:35-48、src/clipboard/panel.cpp:759。
- 上下键选择、Home/End、翻页、直接输入检索、Ctrl+F、空格预览、Ctrl+D 收藏、F2 固定面板：src/clipboard/panel.cpp:745-770。
- 焦点与目标进程校验、等待按键释放、失败时提示手动粘贴、固定面板连续插入：src/clipboard/panel.cpp:587-650。不能因此声称已通过真实第三方应用验证。
- 会话加密磁盘载荷、摘要加异步全文检索、退出清理不恢复：docs/mcp-clipboard-session-storage.md。会话保留是既定选择，不视为缺陷。
- 异步 Quick Look、错误状态、预览取消和资源限制：docs/mcp-clipboard-preview-focus-fix.md。
- 现有限额 100 条、64 MiB 总载荷、16 MiB 单条，收藏占满会拒绝新条目：src/clipboard/history.h:27-46。
- 现有隐私格式检查：src/clipboard/native.cpp:14-18。

README.md 与 docs/mcp-clipboard-history.md 中“仅内存”“不支持富文本”等描述已与当前实现不一致。本轮不直接改写原文，后续应同步文档。

## P0：可靠性与隐私

### 1. 图片恢复格式兼容

src/clipboard/native.cpp:26-28 明确只保留 PNG / DIBV5 / DIB 中一种，且图片存在时丢弃同条 CF_HDROP。Write 仅重放保存格式。因此首次截图支持“粘贴为文件”，不等于从历史重新复制仍能粘贴为文件；只支持 DIB 的接收端也可能无法消费 PNG-only 记录。

建议：内部仍保留一份规范载荷，发布时按需生成 PNG 与 DIB/DIBV5；按用户设置生成 CF_HDROP 临时文件。编码放后台，有容量限制与租约清理，不因清空历史而过早删除已发布文件。先验证记事本、Word/Excel、浏览器编辑框、聊天软件和资源管理器的合成样本矩阵，避免声称通用兼容。

### 2. 暂停记录与应用排除

增加“暂停记录”独立状态，保留既有会话历史且仍能搜索粘贴；不要复用会清空历史的关闭开关。提供明确状态及手动恢复，按需增加定时恢复。增加来源进程排除；进程未知时明确规则，不以窗口标题包含某词作为唯一判断。

补充 Clipboard Viewer Ignore 检查。现有三类隐私标志继续保留。密码/验证码识别最多作为可选启发式，不作防泄密保证。屏蔽条目不生成摘要、缩略图或内容日志。

### 3. 容量和失败提示

拒收超大内容、收藏占满、磁盘写入失败时给出可理解且不频繁打扰的提示。展示条数与容量占用。保留现有粘贴失败回退，增加真实应用验证，而非重写已有焦点逻辑或将 SendInput 成功当作目标已接收。

## P1：高频效率功能

### 4. 历史图片动作

给图片条目提供识别文字、创建置顶贴图、另存为、复制为文件；优先复用既有 OCR 与贴图模块，用户触发才识别，取消后丢弃过期结果。当前剪贴板模块未发现这些动作，不代表整个应用缺少 OCR。

### 5. 多选与合并

Ctrl/Shift 多选、批量删除/收藏，先做文本合并粘贴和可选分隔符，后做明确可见的顺序粘贴队列。队列默认不自动发送 Enter、不自动提交表单；取消或目标变化时停止，避免错误填表。

### 6. 文本轻量编辑和变换

独立编辑动作，默认生成新条目以保留原文。提供去首尾空白、合并换行、大小写转换等少量高频命令。纯文本粘贴已存在，不作为新增功能。F2 已用于固定面板，不能直接照搬其他软件的 F2 编辑快捷键。

### 7. 更快查找与快捷粘贴

在现有全文检索上增加匹配高亮、时间/来源应用筛选、收藏备注与关键词；来源元数据尽量只存应用名而不是敏感窗口标题。支持面板内 Alt+1…9 粘贴可见条目，不抢普通数字搜索输入。需保证输入法候选阶段不误触。

## P2：有需求再做

- 可选常用片段库：明确区别于会话收藏。只有用户再次确认长期保存后才持久化，不能擅自改变原保留策略。
- 可配置容量：先补齐状态与驱逐说明，再考虑提高 100 条限制及检索索引成本。
- 拖出文件/图片、在资源管理器定位、失效路径提示；历史文件路径不等于文件备份。
- 不优先：云同步、账户、AI 自动上传/总结、通用脚本插件、全量磁盘索引。

## 推荐实施顺序和验收

1. 图片多格式恢复 + 隐私忽略标记 + 暂停记录/应用排除。
2. 历史图片 OCR/贴图/保存 + 文本编辑与多选合并。
3. 来源检索、备注、数字快捷取用；根据实际需求再讨论常用片段库。

用合成数据验证：历史恢复图片能覆盖指定目标；暂停期间不新增且旧历史不丢；敏感标记条目不落盘；多选顺序可预测；取消任务不晚到写剪贴板；失败可手动恢复。真实应用、中文输入法和混合 DPI 验收需另行安排。本次未运行测试，不引用既有测试通过记录作为当前版本新验证结果。
