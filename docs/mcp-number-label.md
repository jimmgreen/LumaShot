# 自定义序号标签与目标点优先的引导线

## 已完成

- 序号属性栏新增直接输入的“自定义标签”，不是额外的标签模式或模式下拉框。
- 默认显示自动序号；填写单行文字替代可见序号，清空或只输入空白则恢复该对象原有的序号。最多 64 个 UTF-16 码元，规范化时不截断代理对。
- 自定义文字采用自动圆角胶囊背景，宽度按 DirectWrite 的实际字形度量计算，使用与绘制一致的 Segoe UI 粗体及回退字体，不按字符数量估算。自动编号原有外形保留，清空标签后恢复。
- 单独保存 `Mark.number_label`，不复用说明框的 `Mark.text`；自定义标签、自动编号和组合说明相互独立。
- 点击属性输入框或双击序号可编辑标签。复用原生 EDIT 与独立合成窗口，保留原生光标和输入法；Enter/返回按钮确认、失焦确认、Esc 取消。标签采用单行编辑，说明仍是多行编辑。
- 标签工具默认值采用 UTF-16 十六进制编码存入工具配置，避免 INI 对引号、分号、等号和首尾内容的特殊处理。
- 引导线：按下固定目标点 → 拖动定位序号或标签 → 松开完成。松开时应用最终坐标，即使中间没有对应鼠标移动消息；不超过 3 像素的点击/微小拖动不产生零长度引导线或撤销记录。
- 其他序号组合仍保持原来的“序号在起点、拖动设置范围”逻辑。
- 标签改字、变长、调整大小、再次移动均更新连接位置；保留远端目标、手工远端折点、说明框自定义尺寸、旋转世界坐标和贴图编辑坐标映射。标签八个缩放手柄保持文字与背景比例，不拉扁文字。
- 属性栏适配窄屏与高 DPI；标签输入浮层在屏幕边缘仍位于当前屏幕内。
