# 铅笔与荧光笔按住 Shift 绘制直线功能实现报告

> 历史实现记录：画笔的 Shift 临时直线已被属性板「自由画笔 / 直线」替代，当前行为见 docs/mcp-pen-line-mode.md。

## 1. 需求与设计规范

在截图和标注工具中，用户经常需要使用铅笔或荧光笔划重点或画辅助线。原本的铅笔（`Tool::Pen`，包括普通笔和荧光笔 `PenMode::Highlighter`）是纯自由落笔曲线轨迹，当需要画笔直的横线、坚线或斜向划线时难以保证平直。

本次实现的功能遵循设计规范：
1. **交互习惯**：
   - 在选择铅笔或荧光笔工具时，如果**按住 Shift 键**拖拽鼠标，当前笔画将自动吸附约束为一条直线。
   - 松开 Shift 键即恢复普通自由落笔手绘曲线。
2. **多向吸附约束（`ConstrainStraightLine`）**：
   - 自动按 45° 步长进行角度吸附：
     - **水平线（0° / 180°）**：Y 坐标严格锁定落笔起点，X 坐标跟随鼠标距离。
     - **垂直线（90° / -90°）**：X 坐标严格锁定落笔起点，Y 坐标跟随鼠标距离。
     - **正斜线 / 反斜线（±45° / ±135°）**：|Δx| == |Δy| 严格对角对齐。
3. **渲染与几何存储优化**：
   - 开启 Shift 约束绘制时，点集精简为 `[start, end]` 两个关键端点，避免自由曲线在直线方向上冗余堆积成百上千个微小抖动采样点，降低 Direct2D 图元渲染负载与内存开销。
