# 贴图滚轮缩放性能优化

日期：2026-09-17

## 范围和证据

仅修改 src/pin/pin.cpp、src/pin/paper.cpp/.h 及新增专项测试/CMake 注册。不更换软件 Direct2D DC + UpdateLayeredWindow 架构，不降低源图分辨率、不更改图片插值方式、不引入常驻渲染循环。此前引导线连接修复和六色预设保留。测试全部使用合成图片，不读取个人图片、配置或剪贴板作为素材。

原实现每个动画尺寸都生成整幅 PaperShadowImage 并重新上传位图；基线每组24帧均重建24次。另有连续输入反复 SetTimer 和重置 easing 起点的问题。基准测量的是生产 ApplyPaper 路径（包含阴影、实际绘制、分层窗口提交及工具栏更新）的整体耗时，不是单独的阴影耗时，也不是完整输入到显示器的延迟。

## 实现

- 阴影改为原生分辨率边角缓存，拉伸均匀边缘条；源图片的绘制逻辑不变。缓存键保留 DPI、样式、半径、卷角、阴影边距及必要的小尺寸信息；大图缩放无需重新生成或上传整幅阴影。
- 分别计算距离场和卷角高斯的支持范围，避免不必要地相加，使720p卷角样式也能稳定复用。小尺寸、卷角尺寸变化、DPI/样式变化仍按需重新生成。
- 阴影分块使用 aliased 分区以避免小数坐标处重复覆盖的接缝；位图仍采用线性插值，纸张和原图的抗锯齿设置恢复原状。可证明透明的中间块不绘制；无缩放时整块直接绘制。
- 连续滚轮只更新目标、锚点及徽标期限，不反复重设16ms动画定时器，也不立即重画旧比例。
- 缓动从最后显示帧的时间重新定向，避免高频输入恰好出现在 timer 之前导致 t 不断归零；保留140ms有限缓动、比例限制、正反滚动和高分辨率滚轮增量累积。
- 锁定、拖动/选区开始、编辑和切换样式时清理动画状态；忽略取消后排队的旧 timer 消息。原有普通/OCR贴图路径及源像素、选择坐标不变。

## 同机前后性能

合成棋盘图片；每组24个实际缩放绘制，比例0.55到0.825循环两次，固定图像锚点。使用 Release /O2 构建、系统实际窗口DPI。未对系统后台负载进行隔离，数值是本次单轮样本而非硬性性能保证。P95采用排序后第23个样本。

## 验证及过程中发现的问题

- 新专项224 PASS / 0 FAIL：锚点和负/小数原点、锁定、高分辨率滚轮、精确终点、源像素不变、缓存复用、旧timer取消。
- 五种样式 × 96/144/192 DPI × 9×5与960×540源图，共30组实际分层窗口表面与原整幅阴影参照比较。最终每个像素RGBA通道差值均为0（测试上限为2）；包含0.35/0.7小数偏移。
- 连续180ms每约2ms发送细粒度 WM_MOUSEWHEEL；最终7次动画tick，滚动尚未结束时比例已推进；锁定后排队timer不改变比例。
- pin_styles：207 PASS / 0 FAIL；paper_appearance：85 PASS / 0 FAIL。
- 普通/OCR贴图完整相关回归：56 PASS / 0 FAIL，包含真实OCR worker、选择与工具栏、反向缩放、徽标消失、DPI映射、编辑、锁定、取消和worker空闲释放。
- 总计572个相关断言通过。构建采用项目 /W4 /WX；src/pin 编辑器错误/警告为0。
- 读取实际生成的卷角渲染预览，纸张、卷角和图片位置正常；实际预览位于 build/pin-zoom-style-0.png 至 -4.png。
- 初版分块在小数坐标产生最大3级通道接缝，专项失败后修正分区覆盖；没有放宽阈值绕过失败。
- 仅保留timer、但仍以每次输入为缓动时间起点的中间版本，曾出现有tick但比例不前进，专项失败；现已按最后显示帧时间修复。
- 初版过大的卷角缓存角区导致720p高DPI部分帧重建，实测出现回退；调整为独立支持范围后重跑，最终六组均无重建。
