# 录制界面与主截图工具面板的风格核对

日期：2026-09-22。范围：当前 LumaShot 工作区源码；主面板指截图后的浮动工具栏。

## 结论

属于同一视觉方向，且已复用部分控件，但不是完全统一的样式实现。当前结论来自源码核对，不是对用户已安装版本的逐屏视觉验收。

| 界面 | 已共用的部分 | 仍独立的部分 |
|---|---|---|
| GIF / 录屏准备面板 | DrawControls 普通按钮、下拉按钮；ToolbarMotion 模式切换模型；TextRenderer | 面板底色与材质实现、Tab 实色蓝底、自绘开关、标签色与字体设置 |
| 倒计时 / 录制 / 暂停 / 收尾条 | 录制面板的浅深主题与 TextRenderer | 自绘图标与即时悬停反馈，未采用主工具栏图标缩放/位移反馈 |
| GIF / 视频预览与导出进度 | 相同录制面板基底、共享普通按钮 | 时间轴、裁剪柄、播放按钮、提示卡及进度卡自行绘制 |
| 放弃、失败等提示 | ShowThemedMessage 使用共用面板色、文字和按钮 | 外层仍属于独立窗口 Acrylic 路径，不是主截图工具栏的冻结背景路径 |
| 系统保存窗口 | 与截图保存流程一样保留系统窗口 | 不要求做成应用内工具栏样式 |

## 可定位的差异

1. **背景材质、描边与阴影**
   - `src/ui/render.cpp:189–206`：主工具栏在冻结背景模糊图上叠加浅色 `0xc4eaf3ff` / 深色 `0xa923354b`，并自行绘制阴影与外描边。
   - `src/ui/controls.cpp:41`：主面板 surface 使用 14 DIP 圆角。
   - `src/recording/panel.cpp:47`、`src/ui/acrylic.h:4–5`：录制面板使用 12 DIP 圆角、浅色 `#f7f9fc` / 深色 `#252c38`，Acrylic 成功时分别用 0.60 / 0.72 填充透明度。
   - `src/recording/worker.cpp:339` 与 `src/ui/acrylic.cpp`：录制独立窗口依赖系统合成；不可用时使用不透明回退。它没有复用主工具栏的自绘阴影与外描边，不能据此断言系统最终完全不绘制阴影。
2. **共享控件之外仍有独立色值**
   - `src/ui/controls.h:27–33` 统一主题强调色是 `#0784ff`，文字颜色由 Theme 给出。
   - `src/recording/panel.cpp:15,41,49–84` 中标签、图标、Tab、开关、裁剪和进度条仍使用独立值，例如 `#0788ff`；普通按钮已经走共享 DrawControls，不能把整个录制面板说成完全独立实现。
3. **文字渲染相同，默认字体请求不同**
   - 主工具栏通过 `src/ui/toolbar_render.cpp:9`、`src/ui/render.cpp:52–54` 使用 TextRenderer；`src/ui/render.h:92` 默认请求 Segoe UI。
   - 录制 `src/recording/panel.cpp:20,36–38` 同样使用 TextRenderer，但显式请求 Microsoft YaHei UI；自绘标签大量使用 10–12 DIP，共享按钮仍为 13 DIP。
   - 实际中文回退字形与视觉差异需要渲染验证，不能仅凭字体名推断最终每个字形都不同。
4. **动效只是部分共用**
   - `src/recording/tab_motion.h` 与现有 `docs/mcp-recording-tabs.md` 对应模式 Tab 共用运动模型。
   - 主工具栏 `src/ui/toolbar_render.cpp:11–18,40–60` 有图标缩放、位移和渐变反馈；录制 `Painter::IconButton` 仅按 hover 立即绘制底板。共用 Tab 动效不代表全部按钮动效相同。
5. **菜单和提示已经主题化**
   - `src/recording/worker.cpp:73–79` 使用 `ui::TrackDropdown`，不是原生弹出菜单；主栏复用相同菜单行绘制，但背景承载方式不同。
   - `src/recording/worker.cpp:257,264,292,295,355` 使用主题提示窗口。系统保存窗口仍按现有设计保留，不列为缺陷。

## 建议与验证边界

若目标是更严格的一致性，优先统一面板底色、圆角/描边、文字色与字体层级、图标按钮反馈；保留准备、控制、预览各自需要的布局，不强行做成同样大小。保留冻结截图与实时独立窗口各自的背景机制，不为统一外观引入持续抓屏。

本轮只读核对生产源码并新增此报告。未修改应用、未构建/打包/安装、未启动录制、未读取个人桌面或剪贴板，也未重跑历史测试。现有文档中的历史测试结果不是本轮测试结果；如后续修改，需补充浅深主题及多 DPI 的合成生产渲染对照和相关交互回归。
