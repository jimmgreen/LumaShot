# OCR 按钮与本地表格分析

框选后，点击图钉旁的 **OCR** 按钮进入识别贴图。普通贴图不自动识别；需要时右键选择“识别文字”。识别过的贴图可用“重新识别”重试。对普通贴图进行标注也不会自动加载模型。

普通文字保持原来的拖选、全选和复制操作。表格识别与文字识别共用一次后台任务，不需要预先选择类型。仅在结构判断可靠时，右键菜单增加“复制表格”；复制操作使用缓存结果，不重新推理。

## 表格复制

- 有框线表格使用水平、垂直线与文字位置还原规整行列。
- 无框线表格使用跨行重复的文字对齐关系；证据不足则保留普通文字结果。
- 复制格式为制表符分列、换行分行，可粘贴到 Excel。内部空单元格保持为空；单元格中的换行转换为空格，避免粘贴时多出一行。
- 第一版面向单个主要规整表格，不还原合并单元格。无框线内容不推断没有位置依据的全空行列。结构恢复不修正模型识别错字，重要文字和数字仍需核对。
- 无框线分析采取保守策略：至少三行、存在一行完整列参考、每列有重复对齐依据，且至少四分之三的格子有文字。复杂混排或不满足条件时仍可复制普通文字。

## 资源与取消

表格分析在现有 OCR 工作进程中运行，不在截图快捷键、选区悬停或普通贴图时加载模型。多张识别贴图共用一个进程，模型空闲退出规则保持不变。关闭贴图和重新识别会取消旧任务，版本检查阻止过期结果回写。图像、文字和表格不上传，不保存识别历史。

## 验证方法

使用项目生成的图像和文字验证规整表格、空单元格、框线变化、段落负例、协议边界及真实模型输出；使用原生菜单和粘贴控件验证“复制表格”的实际剪贴板内容。工具栏测试覆盖窄屏、负坐标显示器、不同 DPI、按钮命中和绘制。所有测试数据均为自建内容。

额外通过本机 Excel 新建空白工作簿的实际粘贴核对，验证行列位置和空单元格。表格线检测的灰度工作缓冲区不超过 1536 × 1536 字节；大图的原始图像内存及 OCR 模型内存另计。
