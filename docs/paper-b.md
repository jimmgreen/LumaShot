# B：圆角纸张与上翘卷角

## 行为

- 外扩纸张边框，右下采用曲线卷起的纸面、亮边和接触阴影；截图保持物理像素 1:1。
- 选字、手柄、标记和工具条统一补偿边框偏移；跨 DPI 仅调整装饰尺寸，不重复 OCR。
- 复制和保存继续导出原图及用户标记，不包含纸张外观。
- 边框空白可拖动，双击关闭；Space+拖动仍可从文字上移动贴图。

## 拖动与透明度

纸面和卷角在同一窗口绘制；阴影采用透明的独立缓存。移动使用一次 `EndDeferWindowPos` 批量提交纸面与阴影的位置，防止先后调用分别移动产生错位。微软文档说明该 API 在单次屏幕刷新周期中更新多个窗口的位置：[EndDeferWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-enddeferwindowpos)。

阴影使用预乘 Alpha，不截取或烘焙桌面背景，纸张内部完全透明；`WS_EX_LAYERED | WS_EX_TRANSPARENT` 让阴影透过鼠标输入。参见 [Window Features](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)。

尺寸/DPI 改变时重新生成阴影，普通移动复用已上传图像，没有常驻刷新循环。4K/150% 的阴影缓存约 35 MiB，属于额外装饰内存；生成用的 CPU 临时图像在上传后释放。

## 验证范围

- 图片四角在纸张区域内；1×1 小图和 100%/150%/200% DPI 布局均有覆盖。
- 实际贴图绘制后裁出内容区域，逐像素与原图比较一致。
- 真实 OCR 贴图仍可选字、调整手柄、标记、导出，DPI 切换不触发重新识别。
- 连续 120 次实际窗口批量位移，逐次验证阴影与纸面偏移一致、阴影生成次数不增加；关闭贴图同时释放阴影窗口。
- `paper-b-preview.png` 使用正式绘制代码生成，用于检查卷角明暗和轮廓。

测试通过不等于所有显卡、刷新率和跨屏组合的动态视觉保证。本机未通过高速录像评估逐帧拖影，不能据此声称任何环境下都绝无破绽。
