# 贴图右键菜单

以独立、按事件绘制的 Direct2D 弹窗替换系统菜单。应用主题在打开菜单时读取；截图和纸张不受主题影响。

- 224 DIP 宽，42 DIP 行高，12 DIP 外圆角；缩小 20% 的细线图标、蓝色悬停、分组分隔线。
- 保留复制所选文字、复制全部文字、复制图片、保存图片、重新识别、关闭贴图。
- OCR 状态显示于顶部；缺少文字或选区、正在保存、正在识别时禁用对应操作。
- 支持方向键、Home/End、Enter/Space、Ctrl+C、Escape；点击外部、失去激活或捕获时关闭。
- 弹窗限制于工作区；异步识别期间关闭贴图后按 ID 重新查找，避免引用已销毁的贴图。

验证：build.bat；ctest 的 pin_menu、pin_interaction、paper_appearance、capture_to_pin 全部通过。
pin_menu 使用合成窗口验证六项命令分派、Escape 和外部点击；检查禁用项及多 DPI/负坐标工作区布局；实际绘制函数生成 pin-menu-preview.png（明暗主题）。


菜单阴影修正：移除 CS_DROPSHADOW 和整数圆角区域，改为带 20 DIP 透明留白的逐像素透明窗口。圆角和高斯渐隐阴影在同一表面绘制；点击命中扣除阴影留白，点击阴影关闭菜单。白底预览同时展示明暗主题，测试覆盖阴影区关闭和实际行点击。


新增操作：菜单顶部增加“标注（空格）”和“锁定 / 解锁（L）”。贴图窗口及菜单均支持快捷键，贴图快捷键忽略长按重复。锁定固定位置和缩放，并禁止空白双击关闭，仍可显式关闭及复制文字。

标注复用原截图编辑工具栏，打开时已选中当前图片；显示区域仅包含图片和工具栏，周围桌面保持可见。支持已有矩形、圆形、箭头、铅笔、文字、马赛克、序号等工具及属性。Enter / 完成更新原贴图，Esc 取消；复制按钮及 Ctrl+C 复制并更新贴图，保存使用原始分辨率。编辑仅缩放预览，标注坐标在提交时映射回原图；不重新采集桌面。

验证：build.bat；pin_menu（八项命令及快捷键）、pin_interaction（锁定、重复按键、标注回调及取消）、pin_annotation（缩放映射与原图像素）、capture_to_pin（真实窗口打开工具栏、绘制、完成和取消）、capture_reselect 全部通过。
