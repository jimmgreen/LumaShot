# 贴图文字选择工具

## 操作

- 拖选文字后显示连续蓝色选区和两端圆形手柄；拖动手柄可扩大、缩小或反向选择。
- 松开鼠标显示浮动工具条：复制、荧光笔、波浪线、直线、删除线。删除线图标的横线穿过 S 中部。
- 工具条在屏幕边缘自动移位，空间不足时翻到选区上方，小贴图也不会裁掉工具条。
- 复制后保留选区；在相同选区再次点击同一标记，可取消该标记。Ctrl+Z 撤销最近一次标记操作。
- Esc 清除选区和工具条；点击空白处清除选择并可移动贴图；双击空白仍关闭贴图。Space+拖动可在文字区域移动贴图。
- 复制/保存图片包含荧光笔和线条标记，不包含蓝色选区、手柄和工具条。文字复制仍使用识别文本。重新识别保留已有标记的位置。

## 验证

使用合成文字、真实 OCR 及窗口消息测试手柄收缩、浮窗显示/隐藏、按钮应用波浪线、四种标记、同选区切换、图像导出隔离，以及原有置顶生命周期与 OCR 空闲退出。

几何测试覆盖跨行和反向选择、Unicode 组合字符、负坐标工作区、100%/150%/200% DPI 与窄屏工具条避让。使用正式绘制函数生成并检查 `build/selection-tools-preview.png`；不使用个人文件或剪贴板内容。

测试中首次字符串预期使用 LF，与程序保留 Windows CRLF 的行为不符；修正预期后选字模块测试通过。

标记采用图片物理像素，文字位置受 OCR 估算精度限制。本次修改集中于贴图选字，不改变截图框选的刷新路径。
