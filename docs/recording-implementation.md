# GIF 与录屏实现及验证

2026-09-16。对应设计：recording-design.md。这里记录已实现功能和实际验证边界，设计文档中的未来要求不能当作已通过的验收。

## 已实现

- 设置新增 GIF、屏幕录制两项全局快捷键，默认 Ctrl+Alt+G / Ctrl+Alt+R。截图保持 Ctrl+Alt+A 或原用户值。支持独立录入、清除、取消、重复检查；主进程应用绑定，设置通过临时文件替换提交，保留未知配置项。
- 托盘增加两项录制入口。同一时刻保持一个捕获任务；重复快捷键唤回录制界面。设置录入期间不分发捕获快捷键。
- 区域、窗口、单屏录制；GIF / 录屏模式切换。准备工具条含帧率、输出宽度、光标和音频开关。默认三秒倒计时后开始。
- 录制中收为 48 DIP 高的单行控制条，支持暂停、恢复和停止。暂停关闭 WGC 会话和帧池，恢复重建，媒体时间轴不包含暂停时长。
- WGC → D3D11 裁剪/缩放/NV12 → Media Foundation H.264 → MP4。实际检查编码 MFT 的硬件属性，硬编不可用时不静默改用 CPU；用户可在更多菜单选择兼容编码。
- 系统声音和麦克风使用 WASAPI，混音后 AAC；GIF 无声。生产音频设备采集代码已接入，当前音频验证是合成音频到 AAC 的文件验证，未采集个人系统声音或麦克风做测试。
- GIF 默认 15 fps / 原始尺寸，不设固定录制时长上限，由用户手动停止；视频优先使用当前显示器刷新率（最高 60 fps，查询失败时 30 fps）及原始尺寸。GIF 临时素材始终保留选区原始尺寸，缩放仅用于导出。准备期间不创建捕获或编码设备。
- 录制后支持真实画面、八张缩略图、播放/暂停。GIF 双手柄选取导出时间段、宽度/帧率下拉、循环开关；视频支持保存和另存 GIF。
- GIF 在后台由临时 MP4 解码并缩放、24 个时间点的有界色彩采样、自适应全局 256 色调色板、误差扩散抖动及 WIC 编码。相同索引帧合并延时，变化帧仅写入差异矩形，保留前帧内容。缓冲不随时长增长。15 fps 的 GIF 延时按 6/7 百分之一秒分配，避免总时长累计偏差。
- 导出可取消；保存先复制到目标目录的临时文件，完成后替换目标，失败不破坏已存在的文件。

## 界面与资源

首轮界面与已认可效果图有明显差距，随后重做为统一面板绘制模块 recording/panel.cpp：分段模式选择、圆角半透明表面、紧凑下拉、图标开关、单行录制条及缩略裁剪时间轴。工作窗口使用与现有设置相同的系统 acrylic 策略，失败时采用不透明回退。

准备工具条约 456×122 DIP（GIF）/544×158 DIP（录屏）；录制条约 316×48 /380×48；预览卡片约 560×490 /640×526。UI 在小工作区自动缩放，屏幕区域保持物理像素坐标。

recording-ui-*.png 是生产绘制代码输出，预览内容是自建合成文档，不是个人文件或实际录制历史。这些图片验证控件布局、文字、颜色和圆角；系统最终桌面模糊效果仍取决于 DWM。

录制使用独立 lumashot_recording_worker.exe。托盘不加载新编解码器，不保留录制 GPU 设备。关闭录制/预览后工作进程退出。WGC 帧池 2 帧，编码 GPU 纹理池最多 8 帧，样本释放回调回收纹理，超时明确失败，不能无限排队。8 帧为当前硬件 MFT 的兼容上限，与早期设计的 3 帧候选不同。录制条按状态事件/秒更新，预览仅播放时启用位置刷新。

## 实际验证

- build.bat：C++20 /W4 /WX 编译通过。
- media_recording：GPU 合成画面经兼容路径与已确认的硬件路径编码成功；解码验证图像变化、帧数、递增时间戳；GIF 解码验证尺寸、裁剪帧数和总延时；取消保存保留旧目标文件。
- recording_window：正常桌面权限下，真实 WGC 捕获自建窗口，经 GPU 和硬件 H.264 输出成功；包含暂停/恢复，65 帧、约 2.17 秒、0 丢帧，尺寸验证通过。受限执行环境会报捕获服务错误，不能用该结果判断功能不可用。
- recording_ui：生产面板按钮范围、GIF 切换、准备/倒计时不创建采集器、紧凑录制条、实际鼠标拖动裁剪手柄通过；从生成的 MP4 读取真实首帧和八张缩略图，MFPlay 初始化、播放与暂停通过。
- settings_dialog：新增 GIF 独立录入、清除录屏快捷键、内部重复检查、隔离文件持久化、保留未知配置项通过；现有设置及截图专项通过。
- recording_performance：20 秒 1080p30 GPU 合成画面 + 合成音频，600 帧、0 丢帧；本机总 CPU 平均约 0.118%，预热私有提交 149.85 MiB，最终 137.36 MiB，预热后峰值 150.34 MiB；AAC 解码得到合成音调。**这是合成编码链路测试，未包含 WGC 桌面场景的全部开销，也不是所有设备的性能保证。** GPU 型号/驱动查询受到当前执行权限限制，未据此作跨设备比较。
- 已运行全部注册回归（真实 WGC 单独在桌面权限下运行）。其余 38 项中，36 项初次通过；capture_latency 在正常桌面权限下复核通过。pin_interaction 两次均报 Clipboard is busy，未通过，不宣称全套测试全绿。未修改相关贴图实现来绕过失败。

## 仍需补充的范围

- 尚未做真实麦克风/系统声同步、混合显卡、HDR、混合 DPI 多屏完整实机验收；HDR 不属于已验证色彩范围。
- 区域首版不跨显示器；窗口尺寸变化会结束并报告错误，尚未实现动态适配。异常中断 MP4 的恢复不作保证。
- 帧率/尺寸等录制参数目前在工具条调整，未持久化为 GIF / 录屏独立设置页；新增全局快捷键已持久化。
- 临时 H.264 和 GIF 都不是无损管线；全局调色板抽样可能遗漏短暂出现的颜色。整屏连续运动不保证显著缩小，原始尺寸 GIF 仍可能较大。
- GIF 预览播放的是临时视频，导出后的最终量化颜色以 GIF 文件为准；暂停播放后面板回到首帧海报。
- 当前提供 build/LumaShot.exe 与配套 worker；打包脚本已加入 worker，未运行安装或替换用户正在使用的版本。

## 本次复用与 GIF 修复验证

- 录制按钮/下拉框使用 `ui::DrawControls`；截图工具条与录制弹窗共用 `ui::Dropdown` 布局、命中及 `DrawDropdownRow`。取消系统 `TrackPopupMenu`，支持锚定控件、屏幕避让、方向键、回车、Esc 和点击外部关闭。
- 设置与录制窗口共用 `ConfigureBorderlessWindow` / `ResizeBorderlessWindow`，移除录制外沿描边；保留事件驱动分层窗口与 DWM 模糊，不添加空闲刷新循环。
- 录制面板和弹出菜单的文字使用现有 `TextRenderer` / LumaText DLL。DirectWrite 负责排版，LumaText 负责字形绘制；线程共享 16 MiB 上限的 CPU 字形缓存。标注文字边界计算拆到 `text_bounds.cpp`，录制进程不必链接完整截图编辑器。
- 新增 `gif_quality`：合成肤色渐变、静止与右下角局部变化；验证自适应色彩误差、原始尺寸、重复帧合并、差异矩形合成、总延时、文件体积和采样取消。比较基线保持相同画布与调色板，故不把降分辨率算作压缩收益。
- `recording_ui` 增加真实弹窗的边框/归属、键盘选择、Esc/外部点击关闭，以及 LumaText 多次重绘的内存增长和空闲 CPU 验证。测试只使用自建画面，不采集个人桌面。
- GIF 预览仍播放临时视频，不能视为最终调色板颜色预览。GIF 默认 15 fps 用于控制导出成本，屏幕高刷新率不直接等于 GIF 播放帧率。
