# 标注对象编辑

选择工具（V）按图形显示控制点。矩形、圆形、文字等采用八点缩放框；上方圆形手柄用于旋转。矩形还有四个橙色圆角控制点，可以分别改变四角半径。方形控制点与编辑框按相同角度旋转。箭头额外提供首尾端点。

Shift 拖动缩放点保持比例；Shift 拖动旋转手柄按 15 度吸附。文字的八个缩放点默认同时等比缩放文字与边框，无需按 Shift；拖大字号增大，拖小字号减小，旋转后的文字保持对侧锚点固定。新建文字按实际排版内容自动收紧边界，双击修改后自动增减宽高；拖动缩放后仍保持自动尺寸，再次编辑保留放大后的字号和旋转，并按新内容更新边界。

文字输入采用独立浮动编辑层，避免图形画布盖住原生文字和插入光标。单击创建、双击全选已有文字；Shift+Enter 换行，Enter、右侧回车按钮或点击外部完成，Esc 撤销本次输入，Ctrl+A 全选。输入框随换行增高，到达选区底部后滚动。编辑时显示浅色或深色圆角面板、柔和阴影、蓝色回车按钮和快捷键提示。编辑底色与当前主题一致；低对比文字仅调整输入预览颜色，导出颜色保持原值。面板和提示不写入图片。旋转文字编辑时暂以水平输入框呈现，完成后保留原来的角度和样式，自动尺寸文字重新贴合内容（包括拖动缩放后的文字）。

`text_edit` 使用合成底图和真实 DXGI 画布验证插入光标、绘制出的文字像素、画布重绘后的窗口层级、中文字符输入、换行增高、快捷键、撤销修改、失焦提交及浅深主题下的颜色对比。预览见 `text-editor-preview.png`。IME 测试覆盖组合输入期间不截获 Esc；完整候选词窗口体验仍需实际输入法验收。

序号组合按命中位置选择编号、附属框或折线。编号和附属框各自具有尺寸控制点；折线具有起点、两个转折点和终点。Ctrl 单击选择整个组合后整体移动、缩放或旋转。折线采用二次贝塞尔圆角连接和圆头虚线。

贴图保存原始底图和标注对象，截图创建贴图时也传递这些对象；重新进入标注时按当前缩放恢复可编辑对象，完成后映射回源图坐标。取消不改变原来的对象。

验证：selection_edit 覆盖旋转命中、旋转后的固定对角缩放、独立圆角、比例与字号、箭头端点、序号部件、撤销/重做、缩放坐标往返；capture_reselect 验证实际指针编辑及旋转文字再次编辑；pin_interaction 验证重新打开后保留底图与对象；另跑 annotation_render、capture_to_pin、pin_annotation。

实绘预览：selection-editor-preview.png，纯图形预览：selection-shapes-preview.png。预览来自正式图形与选择控件绘制代码。
文字属性栏提供字体下拉框，列出本机已安装的常用字体（微软雅黑、宋体、黑体、楷体、仿宋、等线和常用西文字体）。输入、自动边界测量和导出共用字体。完成输入后可直接切换字体；已有文字双击进入文字属性后也可切换，支持撤销，手动尺寸框保持原尺寸。
文字工具下点击已有文字会编辑原对象，不会叠加新文字；缩放后再次确认输入会更新内容和边界，保留当前字号。进入文字编辑会结束未完成的拖拽，避免后续鼠标抬起覆盖已修改的内容。
