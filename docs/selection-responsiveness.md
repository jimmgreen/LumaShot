# 框选刷新优化

2026-09-15

- 拖动框选、移动选区和调整范围时，在处理鼠标事件后提交重绘，避免持续鼠标消息使低优先级 WM_PAINT 延后。
- HWND 渲染目标使用立即提交，避免 UI 线程依次等待各显示器垂直同步；桌面合成器负责最终显示。未增加常驻刷新循环。
- 亚克力只采样和绘制面板对应区域；文字格式按字号缓存，上限 32 项。

## 验证与限制

`build.bat` 通过。5 项相关 CTest（截图、标注绘制、颜色面板、贴图图像、截图到贴图）通过；重新检查实际合成渲染预览。

窗口交互测试连续发送 120 次框选移动，验证每次返回后更新区域已绘制，再完成调色与置顶流程。没有使用个人内容。

1080p 合成单窗口 120 次热绘制：中位数 0.252 → 0.2041 ms，P95 0.3838 → 0.3214 ms。该测试原本就未复现明显慢帧，不能据此认定已复现用户卡顿原因，也不是屏幕显示延迟或实际帧率。鼠标消息提交路径已做针对性改善，真实多屏和高刷新率体验仍需实机观察。
