# 标注属性保存

工具栏确认的颜色、线宽、画笔与荧光笔参数、线型、箭头类型及箭头大小、字体字号、文字对齐与背景、填充与圆角、序号样式以及马赛克参数会保存在 `%LOCALAPPDATA%\LumaShot\settings.ini` 的 Tools 节。

下一次截图、贴图标注以及重启应用后，继续使用已保存的参数。仍从选区工具开始，不恢复旧截图、选区、标注内容或打开的菜单。现有共用参数继续共用，画笔与荧光笔保留各自的颜色、宽度和透明度。

颜色选择器取消不保存预览颜色；下拉选择和滑块松手后记住参数。连续调整通过一次性 400 毫秒计时器合并保存，结束截图或退出时补存待保存参数，不增加空闲渲染循环。演示及诊断模式不读写个人属性。无效配置字段回退到默认值，其余有效字段仍可恢复。

验证使用临时生成的配置及合成画面，没有把用户配置或个人截图当作测试数据。专项覆盖所有属性往返、浮点精度、透明填充、异常配置、下次会话状态、确认与取消，以及诊断隔离。构建与包含属性、工具栏、选区、贴图、箭头和文字编辑的 10 项测试通过。
