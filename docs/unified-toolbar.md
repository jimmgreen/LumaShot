# 统一截图面板与公共控件

## 行为

截图完成框选后，初始选择工具只显示紧凑按钮栏。切换到矩形、圆形、箭头、铅笔、文字、马赛克时，用 160 毫秒线性动画展开属性区；切回选择时收起。操作按钮保留一行；窄屏时整行移动到工具下方。快速反向切换从当前高度继续。系统关闭界面动画时直接切换，定时器只在动画期间运行，结束和截图取消时移除。颜色区为红、蓝、深色、白色四个圆角色块，末尾彩色圆点打开已有的自定义颜色面板。

紧凑状态下，工具按钮和操作按钮的垂直中心与工具栏一致。公共提示控件使用与绘制相同的字体测量文字，宽度为文字实际宽度加左右各 9 DIP 内边距；默认在对应按钮上方居中，顶部空间不足时才移到按钮下方，屏幕边缘自动限位。

矩形和椭圆支持无填充、预设填充色、填充透明度；矩形支持圆角。透明度显示 0–100%，100% 表示完全透明。滑块捕获鼠标，拖出轨道仍能连续调整，松开释放。填充和圆角同时应用于标注预览、图片导出与撤销重做。

## 控件复用

- `src/ui/controls.*`：公共面板、分组、按钮、色块、下拉框、滑块、标签、分隔线，以及统一命中检测和可复用的线性过渡计算。绘制和输入使用同一份控件几何数据。
- `src/ui/toolbar.cpp`：只负责布局、控件声明与属性状态。颜色值集中在 `ToolbarColor`，不在事件处理和绘制中重复维护。
- `src/ui/toolbar_render.cpp`：将公共控件接入现有文字、图标和亚克力资源。彩色圆点按渲染目标缓存，使用预乘透明通道，透明边角透出背景。
- `src/app/application.cpp`：执行按钮命令和滑块捕获；不实现另一套控件画法。

这次公共控件用于统一截图面板。既有自定义颜色弹层和贴图选字浮条仍保留各自的专用实现。

## 验证

执行 `build.bat` 和完整 CTest。结果见 `unified-toolbar-tests.txt`。

验证覆盖 100%、150%、200% 缩放、窄屏与负坐标布局、控件命中与互不重叠、动画中途反转、隐藏属性不响应点击、明暗主题的收起状态、真实合成窗口展开后滑块边界与捕获释放、真实渲染输出的填充透明度和圆角、自定义颜色圆点在明暗背景下没有黑色方角、截图后通过统一工具栏创建贴图。

`lumashot_toolbar_test build/toolbar-controls` 生成工具状态及悬停提示的合成内容预览和面板裁图，用于视觉检查。它们使用程序实际的 Direct2D 绘制代码，不使用用户截图或剪贴板内容。自动交互使用合成截图窗口；本轮没有重新让用户进行真实桌面主观流畅度验收。此前已验证的按帧就绪绘制路径继续保留。

## 重新框选

已选区状态下，从原选区外、工具栏外按下左键拖动，会清空原标注、草稿和撤销/重做记录，立即开始新框选，结束后回到紧凑的选择工具栏。鼠标在可重新框选的区域显示十字光标。选区内部移动、边缘控制点调整保留原标注；导出进行中不允许替换。重新框选沿用本次冻结的无界面截图及鼠标资源，不重新抓取桌面。

capture_reselect 使用合成图像和应用实际输入处理函数验证反向拖动、负坐标、历史清空、重叠选区导出不残留标注、移动与调整大小以及导出忙碌状态。

### 连续框选最后一帧回归

本轮连续突发鼠标输入测试复现了最后一帧未提交：frame_wait_result=1（一个帧事件之外的消息唤醒）之后，GetMessage 等了约 220 ms 才返回退出按键，期间 mode=2 的绘制只有 frame_deferred。原始耗时和消息编号见 reselect-frame-wait-before.csv。消息唤醒可能仅来自同步/内部消息，不能假定随后 GetMessage 会立即返回。主循环改为 PeekMessage 非阻塞取消息，再统一用 MsgWaitForMultipleObjectsEx 等待帧或消息；不增加空闲刷新循环。
